# 인증과 데이터 관리

관리자 인증과 저장 범위를 통해 캠핑장 운영 정보와 여행 데이터를 관리한다.

## 역할별 접근

| 역할 | 인증과 처리 방식 |
| --- | --- |
| 차량 앱 | 서버가 선택한 공용 프로필에 여행·장바구니·주문을 저장 |
| 관리자 | 비밀번호와 서명 세션으로 로그인하고 BFF를 통해 운영 기능 사용 |
| API·worker | 서버에 보관한 관리자 토큰으로 관리 요청과 캐시 갱신 수행 |

관리자 BFF는 세션과 요청 출처를 확인한 뒤 API에 전달한다. 공급자·DB 상태, 캠핑장 수령 조건과 주문 처리 정보를 운영 화면에서 관리한다.

## 저장과 비밀 정보

데이터는 저장 범위와 프로필로 구분하며 복합 외래 키로 같은 범위의 여행·장바구니·주문을 연결한다.

공급자 키·DB 자격증명·관리자 인증 정보는 서버의 비공개 환경설정으로 관리한다. Android 앱에는 접속할 API 주소를 설정한다.
