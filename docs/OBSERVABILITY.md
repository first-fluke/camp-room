# 앱 진단과 사용 흐름 분석

캠프룸은 화면 이동과 API·SDK 작업을 정해진 이벤트로 기록해 연결 상태와 이용 흐름을 살핀다. 기본 구성은 앱 전용 저장소의 로컬 진단이다.

## 기록의 역할

| 기록 | 활용 방식 |
| --- | --- |
| 로컬 진단 | 화면·작업·연결 결과를 앱 전용 저장소에 보관 |
| 선택형 사용 기록 | 사용자가 켠 뒤의 준비 체크·단계 변경·가져오기 횟수를 기기에 집계 |
| Sentry 연결 | 프로젝트와 외부 전송을 설정한 빌드에서 크래시 요약 전달 |
| PostHog 연결 | 프로젝트와 외부 전송을 설정한 빌드에서 화면·동작 이벤트 전달 |

선택형 사용 기록은 동의 상태에 따라 관리하며 사용자가 끄면 집계를 초기화한다.

## 데이터 관리

이벤트 속성은 허용 목록에 정의한 상태·종류·수치로 구성한다. 진단 요약에는 예외 종류와 코드 위치를 사용한다.

PostHog는 프로세스 단위 익명 식별자를 사용하고 이벤트를 전송하기 전에 속성 정책을 적용한다. 수집 프로젝트와 전송 옵션은 빌드 설정으로 관리한다.
