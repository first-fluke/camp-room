# Camp Room SDK 적용표

Pleos Connect의 5개 SDK를 여행 준비와 차량 화면에 연결한다. 선언 기준은 [제공 SDK 명세](pleos-sdk.spec.jsonl)다.

| SDK | 버전 | 제품에서 맡는 역할 |
| --- | --- | --- |
| Vehicle | 2.3.2 | 배터리·온도·기능별 영역 관측, 지원 범위에 맞춘 장면 요청 |
| NaviHelper | 3.0.5 | 목적지 예상 주행, 경로 미리보기, 안내 상태·충전 경유 표시 |
| TextToSpeech | 3.3.1 | 일정·날씨·규칙·차량 정보를 선택한 한국어·영어로 안내 |
| SpeechToText | 3.3.1 | 인식한 말을 내비·차박 명령 미리보기로 연결 |
| FusedLocation | 1.1.3 | 최근 위치 기반 주변 정렬, 캠핑장 500m 진입·이탈 알림 |

## 앱에서의 사용

Pleos 빌드는 차량 내 SDK를 직접 사용하고, demo 빌드는 개발용 차량·내비 시뮬레이터와 Android 위치·음성 서비스를 사용한다.

차량 화면은 원본 기능 영역·관측값·출처·표본 시각을 함께 보여 준다. 요청 목표와 관측값을 구분하고 기능별 지원 범위·권한·주차 확인 조건에 맞춰 요청을 처리한다.

위치 알림은 등록·진입·이탈 상태를 각각 표시한다. 경로 미리보기와 안내 상태도 해당 SDK 응답에 따라 갱신한다. 앱을 다시 열면 현재 값을 조회하고 화면에 필요한 관측을 이어간다.

음성 안내와 인식은 기기 내 음성 경로를 사용한다. 인식 결과는 미리보기로 보여 주며, 장면·길안내 실행은 사용자가 화면에서 확인한다.
