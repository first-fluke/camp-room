# Camp Room 검증·사업 계획

기준일: 2026-10-28. 고객 인터뷰, 제휴, 결제, MAU와 유지율 실적은 현재 없다. 아래 수치·일정·판정 기준은 실행 전 가정과 계획이다. 이 문서 작성은 외부 모집·접촉·배포·비용 지출을 실행하지 않는다.

## 해결할 문제와 차별화 가설

반복 캠핑 운전자가 장소 탐색, 일정, 준비물, 차량 상태를 여러 화면에서 확인할 때 같은 여행의 맥락을 다시 맞추는 부담이 있다는 가설을 검증한다. 핵심 제안은 동일 여행의 도착–체류–철수 정보를 이어 주고 실제 차량 관측을 다음 준비에 반영하는 경험이다. 현재 제공하는 탐색·저장·준비 목록·차량 관측과 앞으로 검증할 문맥별 안내를 구분한다. 배터리 관측만으로 체류 가능 시간이나 귀환 가능성을 단정하지 않는다.

## 시장 맥락과 도달 가정

문화체육관광부·한국관광공사의 「2026년 야영장 사업자 안전교육 매뉴얼」(160쪽)은 한국관광공사(2025)의 「2024년 기준 캠핑 이용자 실태조사」를 인용한다. 공식 교육자료는 휴식과 가족·친구와 보내는 시간을 주요 캠핑 동기로 소개하며(PDF·인쇄 12쪽), 연간 평균 캠핑 횟수를 5.6회로 설명한다(PDF·인쇄 19쪽). 이는 체류 경험과 다음 캠핑에서의 재사용을 설계하는 참고 근거이며 Pleos 고객 수요나 시장 규모를 입증하지 않는다. [고캠핑 공식 교육자료 원문](https://gocamping.or.kr/zboard/printFileDown.do?atchFileId=file_100000003814&fileSn=0&lmCode=notice).

별도 조사자가 내려받은 PDF와 해당 페이지 이미지로 위 문구를 재확인했다. 이번 문서 편집 도구에서는 다운로드 MIME 제한으로 PDF를 직접 재열람하지 못했다. 교육자료의 동기 수치는 단위·표본·분모·복수응답 여부를 확인하지 못해 백분율을 인용하지 않는다. 5.6회의 표본·가중치·이용자 정의도 원조사에서 확인하지 못했다. 교육용 요약을 원조사 전체 검증이나 EV·Pleos 설치 가능 고객의 수요 조사로 취급하지 않는다.

초기 MAU 300은 실적이 아닌 검증 목표다. `고유 설치자 600명 × 월 핵심 이용률 50% = 300명`은 가정이다. 여기서 600명은 같은 평가 종료일까지 30일의 관찰 기회를 확보한 설치 완료자의 고유 인원이며, 재설치·업데이트·여러 기기를 중복 설치자로 세지 않는다. 50%의 분모는 이 고유 설치자 전체, 분자는 종료일 직전 이동 30일에 아래 성공 기준의 핵심 행위를 한 고유 인원이다. 중단·삭제·미응답자를 분모에서 조용히 빼지 않으며, 측정 결측과 동의 철회는 별도 수로 보고한다. 이 인원 구분을 현재 로그만으로 구현·측정했다는 뜻은 아니다.

예시 유입 경로 `적격 고유 도달 5,000명 × 신청 30% × 설치 완료 40% × 월 핵심 이용 50% = 300명`도 아직 확인된 채널이 아니다. 단계별 전환율의 분모는 직전 단계의 중복 제거 인원이며, 설치자에게 필요한 관찰 기간을 확보한 뒤 최종 이용률을 평가한다. Pleos 차량·앱 배포 가능 범위, 모집 가능한 적격 운전자와 설치 경로를 먼저 확인한다. 전체 캠핑 인구를 설치 가능 고객으로 간주하지 않는다.

## 사전 승인 후 실행할 6주 검증

| 단계 | 대상·방법 | 기록할 근거와 판단 |
| --- | --- | --- |
| 1주차 | 반복 캠핑 운전자 8명에게 최근 실제 준비 과정을 인터뷰 | 어떤 도구를 언제 썼고 무엇을 빠뜨렸는지 사례로 기록. 원하는 기능을 물었다는 사실만으로 수요를 확정하지 않음 |
| 2–3주차 | 사용자 12명, 기존 방식과 Camp Room의 과업 순서를 교차 배정 | 장소 찾기·저장·필요 정보 재확인의 시간, 화면 이동, 도움 요청, 상태 오해. 소표본 탐색이며 일반화하지 않음 |
| 3–4주차 | 캠핑장 운영자 3곳 조건 확인 | 데이터 정정·연락·예약 연계 가능 범위와 실제 비용. 제휴 의향과 체결을 구분 |
| 4–6주차 | 실제 배포가 가능할 때 30명 첫 과업 관찰 | 설치 성공·첫 여행 저장·준비 목록 완료·중단 원인. 배포 전에는 이를 실적으로 기재하지 않음 |
| 후속 | 동의한 사용자 대상 30/90일 코호트 | 다음 캠핑 기회가 있었는지와 재사용을 함께 조사. 재캠핑 응답자 재사용 40%는 목표이며 전체 유지율과 구분 |

12명 교차 비교는 실행 전에 다음 방법을 고정한다. 장소 찾기·저장·필요 정보 재확인의 세 과업에 대해 조건 수, 정보량, 날짜·지역과 성공 기준이 같은 난도의 시나리오 A/B를 준비하고, 두 방식에서 필요한 정보에 실제로 접근 가능한지 사전 점검한다. 기존 방식은 참여자가 사전에 정한 평소 도구로 고정한다. 서로 다른 시나리오로 기억 효과를 줄이고, `기존 A→Camp Room B`, `Camp Room A→기존 B`, `기존 B→Camp Room A`, `Camp Room B→기존 A`에 각 3명을 배정한다. 공통 연습 과업은 측정에서 제외하며, 본 과업의 안내·도움 기준과 화면 이동 집계 규칙은 동일하게 적용한다.

과업별 제한은 10분이다. 제한 시간 내 성공 기준 미충족·포기는 실패로 기록하고, 주 분석에서는 해당 과업에 600초를 부여해 성공 사례만 남기는 편향을 막는다. 도움을 받는 시간도 소요 시간에 포함하고, 도움 횟수·실패율·기술 오류·중단 이유를 별도로 공개한다. 동의 철회로 분석할 수 없는 자료는 제외하되 철회·결측 인원과 각 분석의 유효 쌍 수를 함께 보고한다.

참여자별 세 과업의 합계 시간을 `T기존,i`, `TCamp,i`로 두고, **짝별 시간 감소율**을 `100 × (T기존,i − TCamp,i) / T기존,i`로 계산한다. 이 짝별 감소율의 중앙값이 20% 이상인지를 제안 판정선으로 삼으며, 두 방식의 중앙값 시간·개별 짝·실패율도 함께 제시한다. 화면 이동도 같은 짝별 감소율 산식의 중앙값으로 30%를 제안 판정선으로 정한다. 기존 화면 이동 수가 0인 쌍은 비율을 만들지 않고 별도 수로 보고한다. 결과에 맞춰 산식·난도·제외 기준을 바꾸지 않는다. 차량 상태를 정상·주차·안전 보장으로 오해한 사례가 있으면 문구와 사용 흐름을 수정한다. 통계적 유의성이나 대표성은 이 표본수로 보장하지 않는다.

## 측정 정의와 개인정보

MAU는 평가 종료 시각 직전 **이동 30일(30×24시간)** 안에 성공한 핵심 행위가 1회 이상 있는 고유 인원으로 정의하는 안을 검증한다. 핵심 행위 후보는 사용자 요청으로 여행 저장이 실제 완료됨, 저장 여행의 장소·일정 데이터가 정상 로드되어 사용자가 이를 열람함, 또는 준비 목록 선택 변경이 실제 반영됨이다. 단순 버튼 클릭이나 API 호출 시작·실패를 성공으로 세지 않으며, 세부 이벤트와 완료 판정은 측정 시작 전에 고정한다. 달력 월 집계가 필요하면 이동 30일 지표와 별도 명칭·기간으로 보고한다. 단순 실행·헬스 체크·자동 경로 미리보기·SDK 폴링은 이용으로 세지 않는다. 현재 프로세스 단위 UUID만으로 앱 재시작을 넘는 고유 사용자를 정확히 중복 제거할 수 없으므로 기존 로그에서 MAU·유지율을 역산하지 않는다.

30/90일 재사용은 각 추적 시점마다 아래 **인원 수와 분모**를 함께 제시한다. 재캠핑 응답자 재사용 40%는 조건부 목표이며 전체 코호트 유지율이 아니다. 응답 여부·재캠핑 기회에 따른 선택 편향을 숨기지 않는다.

| 기호 | 정의·함께 보고할 값 |
| --- | --- |
| `N전체` | 해당 시점의 추적 대상 전체 코호트 고유 인원. 철회·결측 수를 별도 표시 |
| `N응답` | 정한 추적 기간에 응답한 고유 인원. 응답률 `N응답/N전체` |
| `N재캠핑` | 응답자 중 추적 기간에 실제 재캠핑 기회가 있었다고 답한 고유 인원. `N재캠핑/N응답` |
| `N재사용` | 재캠핑 응답자 중 그 기회와 연결된 핵심 행위 재사용을 확인한 고유 인원. 조건부 재사용률 `N재사용/N재캠핑` |

분모가 0이면 비율을 산출하지 않는다. 자기보고만 있는 재사용과 동의 범위의 이벤트로 확인한 재사용은 별도 수로 보고한다. `N재사용/N전체`를 제시할 때는 미응답자의 실제 행동을 알 수 없는 **확인된 재사용 비중**으로 표시하며 전체의 참 유지율로 단정하지 않는다.

지속 식별자나 외부 분석 서비스는 현재 추가하지 않는다. 후속 측정은 동의·보존 기간·철회 방법을 먼저 설계하고 필요한 승인 후 적용한다. 정밀 위치, 차량 식별자, 원본 음성, 연락처를 성과 표에 수집하지 않는다. 실험 참여자 번호와 집계 결과를 분리하고, 정성 인용은 별도 동의가 있을 때 익명화한다.

## 단위경제: 전부 미검증 가정

월 이용료 2,900원, 매출 차감률 15%, MAU당 월 변동비 100원, 월 고정비 100,000원, MAU 300을 가정한다. 이는 실제 Pleos 수수료나 공급자 견적이 아니다. 인건비·세금·검증·고객 획득·고객 지원·환불·법무 비용 등을 제외했으므로 실제 수지는 더 낮을 수 있다.

| 유료 전환 가정 | 유료 사용자 | 차감 후 월매출 | 변동비+고정비 | 비용 차감 후 |
| --- | ---: | ---: | ---: | ---: |
| 3% | 9명 | 22,185원 | 130,000원 | -107,815원 |
| 5% | 15명 | 36,975원 | 130,000원 | -93,025원 |
| 10% | 30명 | 73,950원 | 130,000원 | -56,050원 |

계산식은 `MAU × 유료 전환율 × 2,900 × (1−0.15) − MAU × 100 − 100,000`이다. 이 가정에서 MAU 300의 월 비용 130,000원을 충당하려면 유료 사용자당 차감 후 매출 2,465원 기준 **유료 53명(약 17.7%)**이 필요하다. 53명일 때 비용 차감 후 645원이며, 제외한 비용을 더하면 이 손익분기점도 높아진다.

유료 전환 3%에서는 MAU당 기여액이 `0.03 × 2,465 − 100 = −26.05원`이다. 따라서 이 단가·전환율·변동비가 그대로라면 MAU를 늘리는 것만으로 흑자화할 수 없다. MAU 300은 수익성을 입증하는 규모가 아니라 초기 검증 규모다. 유료 전환·지불 의향, 실제 서비스 비용·배포 요율을 확인하기 전 수익 전망을 확정하지 않는다. 현재 결제·충전·유료 서비스 가입은 수행하지 않았다.

## 네 항목의 수용에 필요한 산출물

1. 차량 특화성: 최종 APK와 설치 해시가 일치하는 관측·콜백·해제 기록, 여행 맥락에서 차량 정보가 필요한 실제 과업 근거.
